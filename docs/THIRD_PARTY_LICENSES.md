# Third-Party Licenses

SendBloom incorporates the following third-party software. Full license texts are available from the upstream repositories.

## r8brain-free-src

SendBloom's ProperSRC path uses [r8brain-free-src](https://github.com/avaneev/r8brain-free-src)
(MIT License, Copyright (c) 2013-2025 Aleksey Vaneev) for bandlimited sample-rate conversion
between host rate and the 32,768 Hz reverb tank core. See [ADR-003](architecture/ADR-003-proper-32k-src.md) and `cmake-local/R8brain.cmake` for integration details.

## JUCE

SendBloom is built with [JUCE](https://github.com/juce-framework/JUCE), the audio
application framework by Raw Material Software Limited, pinned as a submodule at
the tag recorded in `.gitmodules`. JUCE is dual-licensed: an open-source
copyleft licence and a commercial licence. SendBloom ships under the commercial
path recorded in [LICENSING_DECISION.md](LICENSING_DECISION.md); that document
also states plainly that selecting a path is not by itself evidence that a
current entitlement covers a given release.

JUCE modules linked into the shipped plug-ins: `juce_audio_utils`,
`juce_audio_processors`, `juce_dsp`, `juce_gui_basics`, `juce_gui_extra`, and
their transitive dependencies.

## Catch2

[Catch2](https://github.com/catchorg/Catch2) (Boost Software License 1.0) is
used for the test suite. It is a build-time and test-time dependency only and is
not linked into any shipped artifact.

---

The exact pinned version of every dependency for a given release is recorded in
that release's `SendBloom-<version>-sbom.json`, generated by
`scripts/release/sbom.sh`.
